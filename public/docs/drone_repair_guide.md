## 二、10大类高频故障·完整详细步骤（通用大疆全系）

> [!WARNING]
> **安全警告：** 在进行内部检查前，请务必卸下螺旋桨，防止电机意外启动造成人身伤害。

### 01. 云台抖动 / 画面倾斜
*   **诱因：** IMU未水平、云台排线磨损、电机轴承进沙。
*   **解决方案：**
    1.  **水平重置：** 将机器置于水平地面，依次执行：IMU校准 -> 指南针校准 -> 云台自动校准。
    2.  **物理检查：** 观察云台结构缝隙是否有微小异物。
    3.  **固件刷新：** 通过 DJI Assistant 2 刷新最新固件。
    4.  **硬件检测：** 若上述无效，基本确认为云台轴臂排线（软排线）受损。

### 02. 图传卡顿 / 意外断连
*   **解决方案：**
    1.  **频段避让：** 城市干扰大，尝试手动将 2.4G 切换至 5.8G（反之亦然）。
    2.  **极性对准：** 确保遥控器天线平面正对飞机。
    3.  **强制重对：** 长按机身电源键及遥控器特定组合键重新“对频”。

### 03. 电池系统异常（鼓包/跳电）
*   **解决方案：**
    1.  **物理判定：** 视觉有隆起或手指按压发软即为鼓包，**必须报废处理，禁止充电**。
    2.  **保养知识：** 智能电池内含保护板，严禁在低于 -10℃ 或高于 40℃ 环境下大电流放电。
    3.  **存储：** 长期闲置务必维持 50%-65% 电量。

### 04. 电机异响 / 阻力异常
*   **解决方案：**
    1.  **手感对比：** 断电状态下，用手拨动四个电机，阻力应完全一致。
    2.  **排异：** 若某电机卡顿，尝试使用压缩空气吹扫。
    3.  **排雷：** 互换相邻电调接口测试，以此判断故障在主控还是电机本身。

### 05. 飞行飘移 / 无法定点
*   **解决方案：**
    1.  **环境检测：** 检查周围是否有强磁场（变压器、钢筋墙、高压电桩）。
    2.  **GPS：** 必须在搜星 >10 颗后方可切换 P 模式起飞。
    3.  **重心：** 检查反光贴或增高架是否导致重心偏差。

### 06. 传感器异常（解锁失败）
*   **解决方案：** 观察 APP 报错代码，常见为“视觉避障系统被遮挡”或“机身过热”。清理视觉探头并等待降温即可。

### 07. 影像黑屏（码流异常）
*   **解决方案：** 优先更换原装 U3/V30 等级的 SD 卡，排除卡顿导致的系统假死。

### 08. 遥控摇杆漂移
*   **解决方案：** 在遥控器设置中进行“摇杆校准”。若校准过程中光标乱跳，需更换霍尔摇杆总成。

### 09. 续航极速衰减
*   **检测点：** 观察单颗电池循环次数（>200次即进入淘汰期）；检查螺旋桨是否存在轻微肉眼难辨的裂隙导致空耗能量。

### 10. 过热强制关机
*   **解决方案：** 检查机身内部散热风扇是否运转。大疆 Mini 系列静态待机极易过热，起飞后利用气流散热即可恢复。

## 三、精密焊接入门全教程（维修必备）

### 1. 核心工具箱
*   **电烙铁：** 建议选用支持 T12 烙铁头的变频焊台。
*   **焊锡：** 63/37 有铅焊锡线（熔点低，更安全）。
*   **辅助：** 强力助焊膏、洗板水、吸锡带。

### 2. 标准焊接流程
```mermaid
graph LR
    A[清理焊盘] --> B[焊点预热]
    B --> C[送锡填充]
    C --> D[撤锡撤烙铁]
    D --> E[洗板水清洁]
```

### 3. 给新手的 3 条忠告
1.  **恒温策略：** 小型元件建议 320℃，大焊盘（电池接口）建议 380℃。
2.  **切忌“堆浆”：** 焊点应呈裙边状、发亮，而非球状。
3.  **保护飞控：** 飞控板上的贴片电阻极小，切勿盲目加热超过 3 秒，否则极易导致焊盘脱落（掉点）。

## 四、万用表使用入门教程（维修必备）

| 模式 | 维修用途 | 判定标准 |
| :--- | :--- | :--- |
| **蜂鸣档/通断档** | 测电路是否短路/断路 | “哔”声响表示通路，无响声且显示 OL 表示断路 |
| **直流电压档 (20V)** | 测电池单芯电压、主板供电 | 单芯正常 3.7~4.2V；若为 0V 表示保护板锁死 |
| **电阻档** | 测电机线圈一致性 | 三相之间电阻应保持极高的一致性，差异超过 15% 需更换 |

> [!CAUTION]
> **绝对禁忌：** 严禁用万用表“电流档”直接对接电池正负极，会导致设备瞬间烧毁甚至电池短路起火。
